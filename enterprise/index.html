What counts as an active repo?

A billable repository is an active, relevant code repository connected to M.A.R.I.A. and used for risk analysis. If it isn't producing signal you act on, it shouldn't be on the invoice.

What doesn't count?

  • Archived repositories
  • Forks, mirrors, templates and docs-only repositories
  • Proofs of concept with no active ownership
  • Repositories with no relevant security signal
